# Sushma Karri — Portfolio

A single-file, self-contained portfolio site (`index.html`) — no build step required.

## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g. `sushma-portfolio`).
2. Push this folder to it:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Source → Deploy from a branch → `main` / `(root)`** → Save.
4. Your site will be live in a minute or two at:
   `https://<your-username>.github.io/<repo-name>/`

## Local preview

Just open `index.html` directly in a browser — no server needed.
